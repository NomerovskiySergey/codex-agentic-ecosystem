# Feature workflow

Read `references/lifecycle.md`. Create feature documents from `assets/feature.md.template`. The feature document is the canonical shared state; agents must update it at every handoff.

No role may advance a status that requires human approval. Evidence must include commands, outcomes, and changed paths, not a claim of success.
