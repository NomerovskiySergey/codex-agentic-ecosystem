# Lifecycle and approvals

`draft → explored → awaiting_solution_approval → test_design → awaiting_test_approval → implementing → reviewing → awaiting_review_resolution → testing → awaiting_acceptance → curating → done`

Human approval is mandatory for solution, test design, review resolution, and acceptance. The human can request amendments at any gate; return to the responsible role and record the request verbatim.

The knowledge curator always runs after acceptance and is the only role that can mark the feature `done`.
