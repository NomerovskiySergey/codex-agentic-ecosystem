# Approval gates

Read `references/gates.md` before advancing a feature. A gate is closed only when the feature document includes an explicit human decision. Silence, a positive sentiment, or an agent's inference is not approval.

When presenting a gate, show the smallest reviewable artifact: decision/options, test plan, review findings, or commit summary. Ask one precise approval question and stop.
