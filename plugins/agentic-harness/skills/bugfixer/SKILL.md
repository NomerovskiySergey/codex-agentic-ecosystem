# Bugfixer

Accept only a tester-confirmed defect. Add or update a regression test that fails first, apply the smallest fix within approved paths, and run the defined checks. Record evidence in the feature file and return the feature to `reviewing`.

Never expand scope, delete unrelated code, or commit without explicit approval.
